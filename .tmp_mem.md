Built-in datasets live in `src/data/hskLibrary.ts` as a DATASETS registry; picker order = registry order.

Order (top to bottom):
1. English Dictionary A1–C1 — definition-anchored rows (Word + Part of Speech + Definition + Synonym + 10 translations), levels A1, A2, B1, B2, C1 (source file had no real C2 rows), languages: en, ar, zh, ru, tk, kk, bg, id, ms, ur, de, MAIN default English.
2. HSK Dataset v8 (Grouped)
3. HSK Dataset v7

Each dataset ships one compact JSON pack per level as a CDN asset; every level carries all its languages for the same Sense ID, so switching MAIN only reorders columns.
